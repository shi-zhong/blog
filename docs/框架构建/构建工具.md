模块副作用：导入模块时会自动执行的方法
```js
// 举例, 下条语句会制造一个全局输出，包含副作用
console.log(10); // has effect
const a = 10; // no effect
```
无副作用声明 `/*#__PURE__*/`

有副作用的语句会被保留，内部可能会采用inline模式填充，使用`/* __PURE__ */`可以让编译器忽略副作用代码。
