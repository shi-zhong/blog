8. diff -vue2
	1. 同级比较
	2. 新前与旧前对比，相同指针后移，直至不同，跳转至新后与旧后;
	3. 新后与旧后对比，相同指针前移，直至不同，跳转至新后与旧前;
	4. 新后与旧前对比，相同 旧前节点移动至旧后节点后方，旧前指针后移，新后指针前移。重复以上操作，若不能，跳转至新前与旧后;
	5. 新前与旧后对比，相同 旧后节点移动至旧前节点前方，旧后前移，新前后移；
	6. 都没比对成功，则将新前到老节点的索引表中寻找，有则复用
	7. 实际上就是碰运气乱找，双指针靠运气优化一下速度。

10. diff3
	1. sameVnode => diff(key, tag, data)
	2. 处理相同前置后置节点
	3. 处理剩余节点，遍历新节点列表，建立索引表：`NodeNew -> NodeNewIndex` 遍历旧节点列表，在索引中查找，如果是同一节点，则将旧索引值，填入新索引位置的数组中source数组。该步骤用于找到复用的旧节点，然后移除不使用的旧节点。
	4. 获取source的最长递增子序列，并记录对应值的索引。遍历新节点列表，如果索引值相等，则不需要移动，反之进行移动。
	5. 另一种移动逻辑，定义两个变量： move 和 pos。遍历老节点(需要复用的部分)，k = 老节点在新节点的位置，pos = 移动过后最后一个节点在新列表的索引， k < pos 则需要移动，否则 pos = k;（记录最后一位元素，若新元素大于该元素则记为不移动，小则移动）（贪心算法下的递增子序列）
	6. 最长递增子序列算法：遍历序列，当 当前节点 小于数组p的最后一个节点，将p中第一个大于该节点的数替换。最后得到一个数组p，数组长度等于递增序列长度，但数据并不正确，需要用一个数组记录替换过程，并且还原。
