1. RGB和HSV色彩空间
建立一个通用数学三维坐标系，垂直于平面的轴为Z轴，水平于平面指向右侧的为x轴，水平于平面指向下方的为y轴
```
	Z
	|
	| _______X
	/
   / Y
```

色彩映射为 (x, y, z) => (r, g, b)

使用rgb色彩空间时， 空间组织表现为一个正方体。
方程 `x = y = z` 为一条从白色到黑色的渐变线。

特殊颜色坐标（归一化）

(0, 0, 0)  => 黑色
(1, 1, 1) => 白色

(1, 0, 0) => 红色
(0, 1, 0) => 绿色
(0, 0, 1) => 蓝色

(1, 1, 0) => 黄色
(1, 0, 1) => 紫色
(0, 1, 1) => 青色

HSV 的色彩空间在视觉上表现为锥形
H 为 色相旋转， S 为饱和度， V为明暗

圆锥尖代表黑色 V通道为0， 圆锥底面代表确定明暗下的色盘， 根据V的数值，在 `x = y = z`下取等比例的一点，作一个小正方体， 不位于坐标轴平面的三个面映射到该圆上。
